STICKMAN LAUNCH PWA

Upload alle bestanden uit deze map naar de root van een gratis GitHub Pages repository of andere HTTPS static hosting.
Open de HTTPS-URL op iPhone in Safari > Delen > Zet op beginscherm.
Bij wijzigingen: upload de nieuwe index.html en wijzig CACHE in sw.js van v1 naar v2, v3 enz.
De game controleert updates wanneer deze online wordt geopend. Updates zijn niet instant en hangen af van browsercache en internet.
